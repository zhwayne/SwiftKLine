# 性能与测量

[English](../performance.md) | **简体中文**

[文档索引](README.md) · [架构](architecture.md)

分别测量加载、计算、主线程绘制和系统呈现。算法复杂度与计算基准仅描述流水线的一部分；设备帧率需要在设备上测量。

## 调度行为

实时快照默认以 **200 ms** 窗口合并。计算期间收到的新消息进入下一批。历史页、恢复与配置失效请求立即处理，可抢占尚未启动的实时定时器。

结构化任务基于不可变输入计算指标，再将结果与对应 K 线一起发布。计算集合改变可能触发全量批次。外部数据更新与 `requestRedraw()` 不触发指标计算。

图例缓存随数据、配置、资源变化或显式重绘请求失效。仅视口和场景输入不会使其失效。内置指标适配器处理配置，业务插件可检查完整发布输入。

## 计算与存储成本

| 操作 | 成本 | 范围说明 |
|---|---|---|
| 有序历史合并 | O(n + m) | 乱序输入需要排序 |
| 实时尾部查找 | O(1) 次比较 | 数组修改仍可能复制存储 |
| 中间查找 | O(log n) 次比较 | 中间插入移动 O(n) 个元素 |
| MA / WMA / BOLL 全量计算 | O(n) | BOLL 定期重建统计以保持数值稳定 |
| MA / WMA / BOLL 后缀更新 | O(period + changedCount) | 不含输出数组复制 |
| EMA / VOL 后缀更新 | O(changedCount) | 不含输出数组复制 |
| RSI / MACD / SAR | O(n) | 全量计算路径 |
| 内置图表完整绘制 | O(visibleCount × seriesCount) | 另计图例、网格、格式化和自定义渲染成本 |

后缀成本以兼容的历史输出和未变化的前缀为前提；缺少种子值、key 或参数变化、前插历史数据都可能需要全量计算。

原始 K 线、已发布快照、输出和计算中输入可以同时存在。不可变数组可能共享存储，直到修改触发复制。指标数量、历史长度和输出类型均影响内存；常数时间尾部查找不意味着整个更新都是常数时间。

## 绘制与独立数据

画布匹配视口。渲染器复用图层，只遍历可见内容。价格路径、图例和十字光标层有各自的失效条件。分时缓存通过数据修订号检测中间 K 线变化。

`RangeLoader` 按 ID 合并分页，并对缓存项排序后发布，主要成本约为 O(pageItems + cachedItems × log(cachedItems))；淘汰也需要排序候选项并使覆盖失效。缓存有界，但大页响应仍会提高峰值内存。

成交标记示例搜索有序事件，并映射到真实 K 线，成本约为 O(log(events) + visibleEvents × log(candles))。网络和排序应在渲染前完成。

## 实践建议

- 保持数据源和插件语义 ID 稳定，使未变的会话与资源可以保留。
- 仅在相关参数改变时注册计算器和渲染器。
- 外部数据或渲染器样式变化使用 `requestRedraw()`。
- 不需要的功能从配置中移除；仅隐藏绘制可能仍有计算或加载。
- 限制分页大小和流缓冲，根据预期事件密度设置范围缓存。
- 在输入变化时准备格式化、索引和解码图像，避免每次绘制重复处理。

## 运行计算基准

```sh
swift run -c release SwiftKLineBenchmark
swift run -c release SwiftKLineBenchmark 100000
```

[基准程序](../../Benchmarks/main.swift) 对比 WMA、BOLL 的窗口公式与滚动实现，并测量包含数组复制成本的 WMA 尾部更新。默认输入为 20,000 根 K 线，固定计算周期为 200；位置参数可改变输入数量，最少为 200。程序输出五轮中位数，并将各轮返回的末值相加作为校验和。校验和可辅助判断结果，但不能代替完整正确性测试。

报告结果时记录硬件、编译器、优化级别、输入数量、周期和命令。耗时包含算法和数组复制成本，不能据此推导设备上完整图表的 FPS 或峰值内存。

## 测量图表交互

| 场景 | 记录项 |
|---|---|
| 首次显示 | 请求、解码、首个一致快照、首次呈现 |
| 周期切换 | 主线程工作、新会话就绪、重连、网络等待 |
| 指标切换 | 资源协调、计算、图例、面板布局 |
| 滚动与缩放 | 可见数量、绘制耗时、帧间隔、卡顿 |
| 实时行情 | 输入频率、批次频率、计算耗时、发布延迟 |
| 长时间运行 | CPU、内存、缓存增长、任务与连接释放 |

先使用固定离线数据和相同指标，再测量真实传输。预热后运行多轮，记录中位数、P95 和分布，区分稳定成本、首次初始化与网络变化。

用 Time Profiler 定位 CPU 热点，用 Allocations 检查临时对象和数组复制。在物理设备上通过合适的 Instruments 记录测量帧率、GPU 工作和卡顿。注明 Debug 或优化构建，以及模拟器或真机环境。

Debug 绘制日志统计的是绘制请求，不是屏幕帧数。缩小探针范围，并与未挂载采样器的运行结果对比。

## 正确性检查

对比性能前运行相关[开发命令](../../CONTRIBUTING.zh-CN.md#构建与测试)。Core 测试覆盖公式、后缀等价性、合并和数值边界。iOS 测试覆盖发布、插件隔离、资源复用、调度与生命周期；示例测试覆盖独立数据和渲染。检查文档链接和编译示例只能验证用法，不能验证运行时性能。
